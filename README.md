# EarthVerse

Public companion site for EarthVerse: 405 evidence-grounded investigations across 199 real Earth-system and natural-hazard event packages.

Live site: <https://cuizhiq.github.io/EarthVerse/>

The website is deployed from this repository with GitHub Actions. Large raster originals that already have browser-safe derivatives are represented by those local previews so the complete site remains within GitHub Pages limits; directly readable evidence files remain available inside the Viewer.
